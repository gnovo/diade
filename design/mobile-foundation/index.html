Screen 01

01Welcome & Google Sign-In

The minimal entry point into the app. Sets the tone of "The Dyad" (two distinct elements forming one shared space) and provides frictionless authentication.

Architectural Notes & Callouts

  1. 1
    The Dyad Symbol Two complementary organic forms balanced with an equilibrium node. Communicates intimacy and partnership without dating-app clichés.
  2. 2
    Google Sign-In Trigger Authenticates via Google OAuth, sidestepping password hashing CPU limits on Cloudflare Workers and pairing with Google Calendar sync.
Security Rule: No public registration form. Session tokens are saved into device hardware storage (iOS Keychain / Android Keystore).
Screen 02

02Space Onboarding

Displayed when a signed-in user does not belong to a space yet. Implements Option A onboarding with clean division between Space Owner and Invitee.

Architectural Notes & Callouts

  1. 1
    Create Space (Owner) User 1 enters a name for the space (e.g. "Our Home"), which generates an 8-character cryptographic invite code with a 7-day expiry.
  2. 2
    Join Space (Invitee) User 2 enters the 8-character invite code. Server checks strict 2-member capacity limit, attaches User 2 as 'member', and invalidates the code.
Capacity Invariant: Attempting to join a space that already has 2 members returns SPACE_FULL and rejects the write.
Screen 03

03Today Dashboard & 5-Tab Navigation

The central coordination hub. Balances actionable daily items with the global Quick Capture bar and bottom tab navigation.

Architectural Notes & Callouts

  1. 1
    Global Quick Capture Bar "Capture first, organise later." Tapping opens the instant-capture sheet to log text, links, or tasks directly into local SQLite.
  2. 2
    5-Tab Main Navigation Persistent bottom tab bar providing access to Today, Calendar, Lists, Home, and Us.
Offline First: Checking off a grocery item or task updates the local SQLite store instantaneously, appending an entry to the outbox to sync when online.
